## 一、本轮动了什么

### 1. `写作引擎.py` —— 生成端（重启即生效）

**① 共享连接句池全部扩容（约 3 倍）**

第一轮 A/B 证明过这个药方有效（`fresh_感悟` 19→45 是独立增益）。这些池子
**跨全部主题共享**——主题素材撞车还能靠"换主题"避开，连接句撞车避无可避，
是篇间相似度 0.206 里的一大块：

| 池 | 原→新 | 池 | 原→新 |
|---|---|---|---|
| SCENE_OPEN | 4→14 | MOMENT（心理句） | 6→14 |
| DIALOG_OPEN | 3→9 | BRIDGE（过渡句） | 6→14 |
| LYRIC_OPEN | 3→9 | OBJ_DETAILS | 20→40 |
| FLASH_OPEN | 3→8 | REFLECT2 | 16→34 |
| FIRST_NEG | 3→8 | TURN_MID | 10→18 |
| SUSPEND_TAIL | 2→6 | ECHO_TAIL | 3→6 |

新增句全部按上轮教训写的：不用 `_SAFE_OBJ` 接不住的"小物件"句式
（`{obj}`句对站台/院子这类"位置词"也通顺）、无套话黑名单词、克制不用感叹号。

**② 骨架形状随机化（SHAPE_SHAKE）—— 主攻骨架集中度**

折返期治的是"结构组合不重复"，但段落**形状**仍近乎固定：
开头→主线→经过→(70%旁支)→点睛→收尾，段数挤在 6/7 两档。`_shake_shape()`
在成文后、交付前对正文段随机整形（新开关，默认开）：

- **合并**（概率 0.30）：相邻两个正文段并作一段（段数 −1）
- **拆分**（概率 0.45）：长段（≥90 字）在句界一分为二（段数 +1），
  两半都必须仍含主线锚点词（`core`，铁则 2 已算好），否则放弃
- **不动**（概率 0.25）

**与上轮失败实验的本质区别**：段落节奏败在"把补字数集中到某几段"——动的是
**句子分布**，把模板句灌进同一段反而放大重复（0.233→0.416）。这次只挪**段落边界**，
句子一个不增、不减、不改，句级分布原封不动，所以不会复发那个病。

**③ 其他**：`STRUCT_COOLDOWN` 15→25；结局感悟池补句
（遗憾 9→14、治愈 8→12、圆满 7→11、开放 6→10）。

### 2. `GRPO训练.py` —— 对策③「生死簿判骨架」写进奖励

- 新增 `_essay_skeleton()`（与 结构体检.py 同一公式）+ `skeleton_repeat_reward()`
- `total_reward` 公式：`base×0.9 + 1.5×去重 + 1.0×长度 + 0.8×反固定 + 1.0×骨架`
- 训练循环维护**滚动生死簿**（最近 20 篇骨架，`--skel-window` 可调）：
  与簿中任何一篇同骨架 → 该样本判 0 分；**同组 8 篇也互判**，后到者死。
  与句级指纹库（撞车判 0）同一哲学，只是从句子层升到结构层——
  "换个词写成的同一篇文章"从此不该再被强化。
- 自检新增【9】：陌生骨架满分 / 同骨架判死 / 判死拉低总分 / 指纹公式与体检一致。

### 3. `训练.py` + 新脚本 `骨架分层采样.py` —— 对策②④（数据端）

```bash
python 骨架分层采样.py --per-skel 40
#   → 骨架分层_训练语料.jsonl（骨架分布拉平后的主语料）
#   → 骨架分层_报告.md（前后对比）
```

- **④ 结构级去重**：每篇算骨架指纹，同骨架桶只留 `--per-skel` 篇，瘦掉同形冗余；
- **② 分层均衡**：拉平后模型学到的先验才是平的——"外部约束治不了内生的先验"；
- `训练.py` 的 `collect_real_files()` 会**检测到分层语料就自动改吃它**
  （作文主料 = 分层语料 + 真题范文，不再直接吃全量 3 万篇）。
  文件不存在则行为与原来完全一致，零风险。
